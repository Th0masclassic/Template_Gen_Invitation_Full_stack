# Download and run

This clean project archive intentionally excludes `node_modules`, generated output, browser profiles and log files.

1. Open a terminal in this folder.
2. Run `npm ci`.
3. Keep or update your `.env` values as needed.
4. Start the project using the same command described in `README.md`.

Open `/wedding` for wedding invitations or `/babyshower` for baby-shower
invitations. The wedding templates, 10 baby-shower templates, custom-template
import flow, and both pack types are included.
